# La red de los Imparables

Visualización de las afinidades temáticas entre los nueve premiados de los Premios Imparables 2026 (Italfarmaco). Las líneas muestran ámbitos de trabajo compartidos; no implican colaboración entre los premiados.

- `index.html`: versión 3D (paleta Italfarmaco).
- `conexiones-2d.html`: versión 2D.

Controles: → / Espacio / clic avanzan, ← retrocede, F pantalla completa, A automático, R reinicia, H ayuda.
