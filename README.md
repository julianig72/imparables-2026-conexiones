# La red de los Imparables

Visualización de las afinidades temáticas entre los nueve premiados de los Premios Imparables 2026 (Italfarmaco). Las líneas muestran ámbitos de trabajo compartidos; no implican colaboración entre los premiados.

- `index.html`: versión 3D (paleta y logo de Italfarmaco). Adaptada a móvil (vertical y horizontal).
- `conexiones-2d.html`: versión 2D.
- `fotos/` y `logos/`: imágenes de los premiados (presentación del cliente y versiones corregidas del vídeo de cierre v3.7) y logo de Italfarmaco.

Controles de escritorio: → / Espacio / clic avanzan, ← retrocede, F pantalla completa, A automático, R reinicia, H ayuda. Arrastrar gira la red y la rueda acerca.

En el móvil: toca para avanzar, usa los botones ‹ › para avanzar o retroceder, arrastra con un dedo para girar, pellizca para acercar y toca un nodo para abrir su ficha.
